# education.in — Global Institute for Advanced Learning & Leadership

A modern, premium, high-converting digital platform engineered for the **education.in** brand. Designed with a prestigious visual palette pairing **trusted neutrals** (alabaster, slate, crisp whites) with **authoritative deep blues** (midnight navy, Oxford blue, electric blue accents, and subtle gold academic honors).

---

## 🏛️ Brand Identity & Aesthetics

- **Brand Name**: `education.in`
- **Tagline**: *"Where Ambition Meets Mastery — The Premier Institute for Next-Gen Tech & Executive Leaders"*
- **Color Philosophy**:
  - **Deep Blues**: `#040914`, `#081426`, `#0B1E38`, `#0F2756`, `#1E3A8A`, `#2563EB`, `#38BDF8` (denoting institutional trust, intellectual rigor, stability, and cutting-edge frontier technology).
  - **Trusted Neutrals**: `#F8FAFC`, `#F1F5F9`, `#E2E8F0`, `#FFFFFF`, `#64748B`, `#0F172A` (providing breathable legibility, executive elegance, and academic clarity).
  - **Accents**: Subtle Gold/Amber (`#F59E0B`, `#D97706`) for academic honors, ratings, and accreditation seals.

## 🚀 Key Brand & Platform Features

1. **Brand Navigation & Global Control**:
   - Distinctive emblem crest logo with `education.in` branding.
   - Dual currency switch: **₹ INR** and **$ USD** with real-time tuition conversion.
   - Global Quick Search modal (`ESC` or Search button) with instant filtering across courses, faculty, and skills.
   - "Student Portal" interactive access button.
   - Mobile responsive drawer navigation.

2. **Executive Hero Section**:
   - Value proposition highlighting Ivy & Silicon Valley co-developed curriculum.
   - Live Trust Metrics: 98.4% placement rate, 140,000+ global alumni, 4.94/5 student rating, +87% average compensation jump.
   - **Interactive Featured Cohort Card**: Real-time countdown timer, seats remaining ticker, lead faculty preview, and instant syllabus access.

3. **Accreditation & Global Hiring Partners Ribbon**:
   - Direct hiring pipeline: Google, Microsoft, Amazon, Goldman Sachs, McKinsey & Co, Apple, JPMorgan, Meta.
   - Accreditations: Global Academic Alliance, ISO 9001:2026 Standards, STEM-Certified, Cryptographic Blockchain Credentials.

4. **Dynamic Program Directory & Course Filters**:
   - Filter by Category (*AI & ML*, *Distributed Systems*, *Executive Leadership & MBA*, *Quant Finance*, *Data Engineering*).
   - Filter by Experience Level (*Beginner*, *Intermediate*, *Executive*).
   - Live Search by skill (PyTorch, Kafka, Kubernetes, RAG, etc.) or faculty name.
   - Course cards displaying duration, next cohort start date, monthly EMI calculation, faculty credentials, and quick enrollment triggers.

5. **Course Curriculum & Syllabus Modal**:
   - Detailed week-by-week curriculum module breakdown.
   - Faculty bios, capstone repository overview, and downloadable syllabus PDF simulation.

6. **Interactive Learning Ecosystem Demo**:
   - Clickable walkthrough of the 4 core pillars:
     1. *Live Interactive Cohorts*
     2. *Zero-Setup GPU & AI Sandboxes*
     3. *1-on-1 Dedicated Executive Mentorship*
     4. *Direct Recruiter Fast-Track Pipeline*
   - Interactive preview viewport simulating live classroom streams, code execution, and interview pipelines.

7. **Tuition & Merit Scholarship Calculator**:
   - Interactive slider and selectors for Program, Experience Level, and Academic Merit Score.
   - Dynamic real-time calculation of up to 40% Merit Scholarship grants.
   - Zero-cost 6-month, 12-month, and 24-month EMI plan breakdowns.
   - Direct "Lock in Scholarship & Apply" action that pre-loads discounts into the enrollment application.

8. **World-Class Faculty Spotlight**:
   - Distinguished professors and industry fellows from Stanford, Cambridge, DeepMind, McKinsey, Citadel, and Harvard.

9. **Alumni Transformations & Verified Reviews**:
   - Verified student cards with before/after roles, company transition badges, and compensation hike percentages.

10. **4-Stage Admissions Roadmap**:
    - Transparent intake journey: Application -> Diagnostic Benchmark -> Faculty Advisory -> Cohort Onboarding.

11. **Free 1-on-1 Strategy Session Booking**:
    - Interactive lead generation form with time slot and career track preference.

12. **Interactive FAQ Accordion**:
    - Complete answers regarding cohort schedules, job placement assistance, financial aid, and working professional flexibility.

13. **Student Learning Portal Interactive Demo Modal**:
    - Working preview of the student dashboard: live class player, browser-based GPU code runner sandbox, and blockchain-verifiable diploma.

14. **Institutional Footer**:
    - Global campuses (Bengaluru, Singapore, London, San Francisco), accreditation links, grievance contact, and executive newsletter subscription.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 with custom deep-blue gradients and typography
- **Icons**: Lucide React + custom inline SVGs
- **Fonts**: Plus Jakarta Sans, Playfair Display, Space Grotesk

---

## 💻 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
